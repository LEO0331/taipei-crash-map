# Taipei Traffic Accident Hotspot Map

**English** · [繁體中文](README-zh.md)

A mobile-first Vite + React dashboard for exploring historical Taipei traffic-accident public data. It uses Leaflet, Recharts, local static JSON, and a PWA-ready app shell; it does not call the Taipei Open Data API at runtime.

## What it provides

- Historical A1/A2 crash points and aggregated intersection hotspots.
- Time, district, crash-type, and location-text filtering, plus optional nearby-record lookup.
- Aggregate crash-factor charts and a citywide annual top-five reported-violation view.
- A separate monthly Traffic Accident Appraisal Reconsiderations module, including procedural counts and A1/A2/A3 composition.
- Traditional Chinese as the default UI, with an English toggle and responsive/PWA support.

## Decision boundary

This is a descriptive exploration tool. Historical counts are not exposure-adjusted risk measures and do not establish causation, fault, legal merit, appraisal quality, enforcement performance, or road safety.

The crash, crash-detail, reported-violation, and appraisal-reconsideration datasets have different units and coverage. Do not merge or ratio them without official-compatible definitions and periods. The reconsideration module is procedural aggregate data only; it is not a case lookup or legal-success measure.

Read the customer-facing recommendations and implementation risks in [Dashboard decision insights and technical notes](dashboard-decision-insights-and-technical-notes.md).

## Data conversion

Browser-facing datasets are generated local files under `public/data/`; raw inputs belong under `data/raw/`.

- `npm run convert:accidents` — main accident locations and hotspots.
- `npm run fetch:crash-details` and `npm run convert:crash-details` — fatal/injury crash-detail aggregates.
- `npm run data:fetch:reported-violations` and `npm run data:convert:reported-violations` — annual reported-violation statistics.
- `npm run data:convert:appraisal-reconsiderations` — monthly appraisal reconsiderations.

The reconsideration source uses ROC `年/月` values (for example, `106年1月`). Its converter preserves raw fields and creates a sortable Gregorian `YYYY-MM` period using ROC year + 1911. Counts and source A1/A2/A3 percentages remain separate.

## Local development

Requirements: a supported Node.js LTS release and npm.

- `npm ci` installs locked dependencies.
- `npm run dev` starts Vite.
- `npm run build`, `npm test`, and `git diff --check` are the release checks.
- `./init.sh` runs build and test checks in Bash-capable environments.

For a conversion-contract change, also run the matching converter and inspect its generated metadata/report.

## Deployment

Deploy the `dist/` directory generated by `npm run build`. The included GitHub Actions workflow builds with `GITHUB_PAGES=true`, using `/taipei-crash-map/` as the base path.

## Project layout

`src/` contains the React app; `scripts/` contains fetchers/converters; `data/raw/` contains source snapshots; `public/data/` contains generated browser datasets; and `tests/` contains utility and conversion-contract tests.
